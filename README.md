# 🛵 Food Delivery Platform (Django Backend)

A backend-driven food delivery application built using Django. This project handles user and vendor management, secure authentication, dynamic cart functionalities, and seamless location-based services using Google Maps Platform API.

## 🚀 Features

- 🔐 **User & Vendor Registration with Email Verification**
- 🗺️ **Location Autocomplete using Google Maps API**
- 📍 Capture latitude, longitude, and postal code from location input
- 🛒 **Dynamic Cart Management** (Add/Delete without page refresh using AJAX)
- 🧠 Role-based access for different user types (Customer & Vendor)
- 🧾 Order placement and tracking logic
- 🧬 PostgreSQL integration for data storage
- ✉️ Email verification system with secure token generation
- 📁 Modular Django project structure with reusable apps
- 📦 Virtual Environment (`venv`) used for isolated package management

## ⚙️ Tech Stack

- **Backend**: Django (Python)
- **Database**: PostgreSQL
- **APIs**: Google Maps Platform (Places API, Geocoding API)
- **Other**: AJAX, Django Forms, Django ORM
